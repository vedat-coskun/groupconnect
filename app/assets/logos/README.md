# Kurum logoları

Kurum (tenant) logolarının PNG dosyaları buraya konur. `Tenant.logoAsset`
bu klasördeki bir dosyaya işaret eder (ör. `assets/logos/atlas_uni.png`).

Dosya yoksa uygulama otomatik olarak kurumun marka ikonuna (`Tenant.logoIcon`)
döner — eksik logo build'i kırmaz.

Beklenen dosyalar:
- `atlas_uni.png` — Atlas Üniversitesi (kare/şeffaf PNG, ideal ~256×256).
